3. Planned TikTok Sandbox integration

The integration is in development and intended initially for the project owner's authorized test account. Public sign-up is not available. If testing is enabled, the requested read-only permissions are user.info.basic, user.info.profile, user.info.stats and video.list. Depending on granted permissions and API responses, these may provide account identifiers, profile information, aggregate account statistics, public video identifiers and metadata, and counts of views, likes, comments and shares. OAuth credentials would be used to maintain the authorized connection. The intended purpose is displaying and monitoring authorized account performance, not accessing private messages or automatically posting, editing or deleting content. No TikTok data will be used for model training unless separately permitted and disclosed.

The initial owner-only Sandbox connectivity test processes the account username and identifier, aggregate account and public video counters, and temporary OAuth credentials in the project's restricted virtual machine memory. It displays only a diagnostic summary (success, number of rows and whether required fields exist) and does not intentionally save API responses or tokens to disk. The test requests revocation at the end; if revocation cannot be confirmed, the account holder must disconnect the test app in TikTok settings. The lawful basis for this optional test is the account holder's consent (GDPR Article 6(1)(a)). TikTok receives the authorization and API requests. Before persistent OAuth or scheduled collection is activated, the operator will specify infrastructure providers, transfers, retention limits, security and deletion arrangements and update this notice. Authorization is optional and may be withdrawn through TikTok or by contacting the operator. For TikTok's own handling of information, see its privacy policy.
