3. Planned TikTok Sandbox integration

The integration is in development and intended initially for the project owner's authorized test account. Public sign-up is not available. If testing is enabled, the requested read-only permissions are user.info.basic, user.info.profile, user.info.stats and video.list. Depending on granted permissions and API responses, these may provide account identifiers, profile information, aggregate account statistics, public video identifiers and metadata, and counts of views, likes, comments and shares. OAuth credentials would be used to maintain the authorized connection. The intended purpose is displaying and monitoring authorized account performance, not accessing private messages or automatically posting, editing or deleting content. No TikTok data will be used for model training unless separately permitted and disclosed.

The initial owner-only Sandbox connectivity test processes the account username and identifier, aggregate account and public video counters, and temporary OAuth credentials in the project's restricted virtual machine memory. It displays only a diagnostic summary (success, number of rows and whether required fields exist) and does not intentionally save API responses or tokens to disk. The test requests revocation at the end; if revocation cannot be confirmed, the account holder must disconnect the test app in TikTok settings. The lawful basis for this optional test is the account holder's consent (GDPR Article 6(1)(a)). TikTok receives the authorization and API requests. Before persistent OAuth or scheduled collection is activated, the operator will specify infrastructure providers, transfers, retention limits, security and deletion arrangements and update this notice. Authorization is optional and may be withdrawn through TikTok or by contacting the operator. For TikTok's own handling of information, see its privacy policy.

3a. Restricted Instagram owner-account testing

The project owner can authorize read-only access to the Sophion Instagram professional account through Meta's Unified Login. The diagnostic retrieves account identity, public Reel identifiers and timestamps, aggregate views, reach, likes, comments, shares, saves, average viewing time and skip rate. It does not retrieve comment text or private messages, and does not post or change content. The owner may elect to keep an access token in a restricted local file on the project's Google Cloud virtual machine, accessible to the operating user and authorized infrastructure administrators. The token is retained until replaced, revoked or the connection is discontinued. Diagnostic API responses are processed in memory; only a summary of field availability is displayed. This optional owner-authorized testing is based on consent where personal data is processed. Meta and Google Cloud provide the relevant API and hosting infrastructure; see Meta Privacy Policy and Google Cloud Privacy Notice. To disconnect, revoke the integration in Meta and remove the local credential; contact the operator for assistance. The planned owner-only monitoring service takes one hourly snapshot of public Reel identifiers, publication and observation times, and the eight aggregate metrics described above, to compare the account's own content performance over time. Once enabled, these snapshots are kept in a restricted directory on the virtual machine for no more than 30 days under normal scheduled operation, or deleted sooner when no longer needed or upon a valid deletion request. Collection pauses on API or authentication failures. Requests for access, correction, deletion or security concerns can be sent to sophion.tradestudio@gmail.com. To discontinue monitoring, the operator will stop the service, revoke the connection in Meta, and remove the local credential and snapshots, including any applicable copies or backups. No public sharing, advertising profiling, third-party account monitoring or model training is enabled by this Instagram collector. The scheduled service remains subject to verification of the applicable Meta terms and hosting arrangements before activation.
